OVERROLL WEB — PASO 7: PERFILES Y AUDIO

1. Detén Vite con Ctrl+C.
2. Arrastra este ZIP dentro de la carpeta web.
3. En la terminal ejecuta:

cd /workspaces/OverRoll/web
pkill -f vite || true
rm -f public/assets/sounds/success.mp3 public/assets/sounds/okay_2FZURrU.mp3 public/okay_2FZURrU.mp3 okay_2FZURrU.mp3
unzip -o OverRoll-Web-Paso-7-Perfiles-Audio.zip
rm -f OverRoll-Web-Paso-7-Perfiles-Audio.zip
npm run dev -- --host 0.0.0.0

4. Abre el puerto 5173.
5. Actualiza con Ctrl+F5.
