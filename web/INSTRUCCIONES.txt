OverRoll Web - Paso 6: Overwatch completo

1. Coloca este ZIP dentro de la carpeta web del Codespace.
2. Detén Vite con Ctrl+C.
3. Ejecuta:

cd /workspaces/OverRoll/web
pkill -f vite || true
unzip -o OverRoll-Web-Paso-6-Overwatch-Completo.zip
rm -f OverRoll-Web-Paso-6-Overwatch-Completo.zip
npm run dev -- --host 0.0.0.0

Después de comprobarlo:

cd /workspaces/OverRoll
git add web
git commit -m "Completa perfiles filtros perks Stadium y sonidos de Overwatch Web"
git push origin web-version

Cloudflare Pages volverá a desplegar la rama web-version automáticamente.
