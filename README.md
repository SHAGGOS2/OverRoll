# OverRoll

Aplicación de ruleta y selector aleatorio para Overwatch.

La hice principalmente para cuando no sabes qué héroe elegir, quieres probar personajes diferentes o simplemente prefieres dejar que una ruleta decida por ti xd.
y mas por el hecho que no habia una tan completa para variar con mis amigos

> **OverRoll es un proyecto fan no oficial de Overwatch, elaborado en su mayoria por CODEX**

OverRoll todavía está en desarrollo, así que algunas cosas pueden cambiar, romperse o mejorar entre versiones. (como todo proyecto feo)

---

## ¿Qué es OverRoll?

OverRoll es una aplicación portátil para Windows que permite seleccionar héroes de Overwatch al azar, crear ruletas personalizadas, guardar perfiles y consultar estadísticas.

No se limita solamente a elegir cualquier personaje. La idea es que puedas configurar qué quieres utilizar dependiendo del rol, los héroes disponibles y la cantidad de resultados que necesites.

---

## Funciones principales

### Selector aleatorio

Puedes hacer que OverRoll seleccione uno o varios héroes al azar.

También puedes decidir qué roles quieres incluir:

- Tanque
- Daño
- Apoyo

De esta forma, si solamente quieres jugar un rol específico, la aplicación no te mandará cualquier otra cosa.

---

### Ruleta Maker

El modo Ruleta funciona como un creador de ruletas personalizadas.

Tú eliges:

- Qué héroes aparecen en la ruleta.
- Qué roles están permitidos.
- Cuántos resultados quieres obtener.
- Qué personajes quieres excluir.
- Cómo quieres organizar tu selección.

No es solamente una ruleta automática con todos los héroes. Cada usuario puede crearla según lo que quiera jugar.

---

### Perfiles

Puedes crear diferentes perfiles para separar configuraciones, preferencias y estadísticas.

Esto puede servir si:

- Varias personas utilizan la aplicación.
- Quieres configuraciones distintas.
- Deseas separar tus estadísticas.
- Juegas de manera diferente dependiendo del modo.
- Quieres experimentar sin alterar tu perfil principal.

---

### Estadísticas

OverRoll guarda información relacionada con las selecciones realizadas dentro de la aplicación.

Dependiendo de la versión, puedes consultar datos como:

- Héroes seleccionados.
- Frecuencia de aparición.
- Roles utilizados.
- Resultados anteriores.
- Estadísticas de cada perfil.
- Uso general de la aplicación.

Las estadísticas pueden cambiar o ampliarse en futuras versiones.

---

### Varios idiomas

OverRoll incluye soporte para varios idiomas.

La aplicación puede adaptar elementos como:

- Menús.
- Botones.
- Mensajes.
- Roles.
- Nombres de héroes.
- Descripciones.
- Contenido adicional.

Algunas traducciones todavía pueden estar incompletas o necesitar correcciones.

También hay ciertos chistes, canciones, referencias y detalles diferentes dependiendo del idioma seleccionado xd.

---

### Sonidos y detalles adicionales

OverRoll puede incluir sonidos, enlaces, canciones, bromas y referencias relacionadas con algunos personajes.

Parte de este contenido puede abrirse desde Internet, por lo que ciertos elementos necesitan conexión para funcionar.

La intención es que la aplicación no se sienta solamente como un selector básico, sino que tenga un poco más de personalidad.

---

## Descargar OverRoll

Las versiones de la aplicación se encuentran en la sección **Releases** de este repositorio.

Para descargarla:

1. Entra a la sección **Releases**.
2. Abre la versión más reciente.
3. Descarga el archivo `OverRoll_Portable.zip`.
4. Extrae completamente el contenido.
5. Abre la carpeta extraída.
6. Ejecuta `OverRoll.exe`.

> No ejecutes `OverRoll.exe` directamente dentro del archivo ZIP.

---

## Aplicación portátil

OverRoll no necesita un instalador tradicional.

La aplicación funciona desde la carpeta extraída, pero es importante conservar juntos todos sus archivos.

No debes separar:

- `OverRoll.exe`
- La carpeta `_internal`
- Las carpetas de recursos
- Los archivos de configuración incluidos

Si mueves solamente el ejecutable, probablemente la aplicación no abrirá correctamente.

---

## Requisitos

- Windows 10 u 11.
- Sistema operativo de 64 bits.
- Espacio suficiente para extraer la aplicación.
- Permisos para ejecutar programas descargados.
- Conexión a Internet para ciertos enlaces o contenidos externos.

No necesitas tener Overwatch abierto para utilizar OverRoll.

---

## Cómo utilizar el selector

1. Abre `OverRoll.exe`.
2. Selecciona los roles que quieres incluir.
3. Configura la cantidad de resultados.
4. Presiona el botón de selección o reroll.
5. La aplicación mostrará los héroes elegidos.

Puedes volver a tirar si quieres obtener otra selección.

---

## Cómo utilizar la ruleta

1. Entra al apartado de Ruleta.
2. Selecciona los héroes que quieres incluir.
3. Activa o desactiva los roles.
4. Elige cuántos resultados necesitas.
5. Revisa que haya personajes disponibles.
6. Gira la ruleta.

Si no seleccionas ningún personaje o excluyes a todos, la ruleta no tendrá resultados que mostrar.

---

## Cómo utilizar los perfiles

1. Abre el apartado de Perfiles.
2. Crea un perfil nuevo o selecciona uno existente.
3. Configura sus preferencias.
4. Utiliza normalmente la aplicación.
5. Consulta después sus estadísticas.

Cada perfil puede conservar información diferente.

## Problemas conocidos

OverRoll sigue en desarrollo, por lo que pueden aparecer errores como:

- La aplicación puede cerrarse al abrir alguna configuración.
- Algunos textos pueden no estar completamente traducidos.
- La ruleta puede aparecer vacía si no seleccionaste héroes.
- Algunas partes de la interfaz pueden verse amontonadas.
- El consumo de memoria todavía puede necesitar optimización.
- Algunos enlaces, canciones o contenidos externos pueden dejar de funcionar.
- Ciertas configuraciones pueden no guardarse correctamente.
- Los nombres de algunos personajes pueden variar dependiendo del idioma.

Estos errores se irán corrigiendo conforme se encuentren y se puedan reproducir.

---

## ¿La aplicación no abre?

Revisa lo siguiente:

1. Extrae completamente el archivo ZIP.
2. No ejecutes la aplicación desde dentro del ZIP.
3. No muevas solamente `OverRoll.exe`.
4. Comprueba que la carpeta `_internal` siga junto al ejecutable.
5. Revisa que Windows Defender o tu antivirus no haya eliminado archivos.
6. No mezcles archivos de versiones diferentes.
7. Prueba extraer la aplicación en una carpeta nueva.

Windows también puede mostrar una advertencia de SmartScreen porque la aplicación todavía no cuenta con una firma digital.

Descarga siempre OverRoll desde la sección oficial de **Releases** de este repositorio.

## Reportar errores

Puedes utilizar la sección **Issues** del repositorio para reportar problemas.

Incluye de ser posible:

- La versión de OverRoll.
- Tu versión de Windows.
- El apartado donde ocurrió el error.
- Qué estabas haciendo antes de que fallara.
- Los pasos para hacer que vuelva a ocurrir.
- Una captura de pantalla.
- El mensaje de error, si apareció.
- El idioma seleccionado.
- El perfil o configuración que estabas utilizando.

Ejemplo:

> Al entrar a Configuración, la aplicación se cierra. Ocurre después de seleccionar el idioma japonés en OverRoll v1.0.0 utilizando Windows 11.

Mientras más claro esté explicado, más fácil será encontrar qué se rompió xd.
