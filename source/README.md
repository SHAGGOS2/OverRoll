# Codigo fuente de OverRoll

- `app.py`: arranque real de la aplicacion.
- `owrp/`: controladores, servicios y modulos de juego.
- `qml/`: interfaz y componentes visuales.

La raiz conserva unicamente el lanzador `main.py`, datos, recursos, pruebas,
herramientas de compilacion y artefactos generados.
